# Student Performance Prediction

A Machine Learning project that predicts whether a student will pass or fail based on academic and behavioral factors like study hours, attendance, assignments, and sleep hours.


# Project Overview

This project uses Machine Learning algorithms to analyze student data and predict student performance.

The main goal of this project is to:

Predict student results (Pass/Fail).
Analyze factors affecting performance.  
Visualize student data using graphs.
Build a simple and interactive user interface using Streamlit.

# Machine Learning Algorithms

This project can use:

Decision Tree (Tried for acuaracy).
K-Nearest Neighbors (KNN) (Tried for accuracy).
Support Vector Machine (SVM) (Tried for accuracy).


# Dataset Information

The dataset contains student-related information such as:

Study Hours
Attendance
Assignment Scores
Internal Marks
Final Result

Target Column:

`0` = Fail
`1` = Pass
